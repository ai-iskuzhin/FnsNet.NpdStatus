# API сервиса «Проверка статуса налогоплательщика НПД»

Конспект [официального описания](https://npd.nalog.ru/html/sites/www.npd.nalog.ru/api_statusnpd_nalog_ru.pdf)
(версия 1.0.0 от 21.02.2019) — то, на что опирается этот SDK.

## Эндпоинт

```
POST https://statusnpd.nalog.ru/api/v1/tracker/taxpayer_status
```

REST, JSON. Авторизации нет.

## Запрос

```json
{
  "inn": "525741209968",
  "requestDate": "2019-01-11"
}
```

| Поле | Тип | Описание |
|---|---|---|
| `inn` | String | ИНН налогоплательщика |
| `requestDate` | String | Дата, на которую проверяется статус, в формате `yyyy-MM-dd` |

## Ответ

```json
{
  "status": true,
  "message": "525741209968 является плательщиком налога на профессиональный доход"
}
```

| Поле | Тип | Описание |
|---|---|---|
| `status` | Boolean | Является ли ИНН плательщиком НПД на указанную дату |
| `message` | String | Сообщение сервиса |

## Ошибки

`422` — бизнес-ошибка, `400` — тело не разобралось, `500` — внутренняя ошибка.

```json
{
  "code": "validation.failed",
  "message": "Указан некорректный ИНН"
}
```

| HTTP | Код | Описание |
|---|---|---|
| 422 | `taxpayer.status.service.unavailable.error` | Сервис временно недоступен |
| 422 | `taxpayer.status.service.limited.error` | Превышено число запросов с одного IP |
| 422 | `validation.failed` | ИНН не проходит ФЛК; дата раньше 01.01.2019; дата позже текущего дня |
| 400 | — | Неправильный формат запроса, например дата `2019-02-00` |

## Правила из описания

- **Не чаще двух запросов в минуту с одного IP-адреса.**
- Таймаут ожидания ответа — **не менее 60 секунд**.
- В ответах могут появляться новые поля и заголовки **без поднятия версии API**; клиент обязан их
  игнорировать.

## Проверено на живом сервисе

Замеры от 01.10.2026, с хоста в России:

| Запрос | Ответ |
|---|---|
| `525741209968` (пример из описания) | `422` `{"code":"validation.failed","message":"Указан некорректный ИНН: 525741209968"}` |
| корректный по контрольной сумме, незарегистрированный | `200` `{"status":false,"message":"… не является плательщиком …"}`, 0.10 с |

То есть **ИНН из официального примера сам не проходит ФЛК сервиса** — скопировавший образец запроса
получит 422 и может решить, что сервис сломан.

Из-за границы хост не резолвится: сервис доступен только из российских сетей.
